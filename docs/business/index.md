# 業務フロー

利用者が何をするかの流れです。個別のフローから、使うAPIへ進めます。

| 名前 | 役割 |
| --- | --- |
| [プロフィールを公開する](プロフィールを公開する/README.md) | ログインした利用者が、本人確認が済んでいるときだけプロフィールを公開中にする |
| [ログインして商品を探す](ログインして商品を探す/README.md) | ログインしたあと、検索語で公開中の商品を探す。ログインできなければ検索には進まない |
| [カードで支払う](カードで支払う/README.md) | パスキーでログインし、カードを登録してから、注文を選んで支払う |
| [パスキーの端末をなくす](パスキーの端末をなくす/README.md) | メールの確認リンクで本人確認し、今までのセッションとパスキーを無効にしてから、新しい端末にパスキーを登録し直す |
